# 📈 자동매매 시각화 및 주문 봇 V2 (Pro Edition)

한국투자증권(KIS) API 및 실시간 웹소켓을 연동하여 차트 시각화, 전략 시뮬레이션, 그리고 실제 주문 집행까지 지원하는 주식 트레이딩 플랫폼입니다.

## 🚀 주요 기능

### 1. 실시간 데이터 연동
- **웹소켓(WebSocket)**: 백그라운드 스레드 기반의 초고속 실시간 체결가 수신
- **계좌 연동**: 본인의 실제 예수금 및 보유 종목 상태를 실시간 트래킹

### 2. 스마트 분할 매매 전략
- **중기 채널 전략**: 1차(30%), 2차(60%), 3차(90%) 기하학적 타점 분할 진입
- **단기 돌파 전략**: 저항선 돌파 시 칼손절(-4%) 또는 여유손절(-10%) 맞춤형 대응
- **트레일링 바이**: 타점 도달 후 **1% 반등 확인 시** 안전 매수

## 🛠️ 설치 및 실행 방법

### 1. 종속성 라이브러리 설치
```bash
pip install -r requirements.txt
pip install websockets
```

### 2. 환경 변수 설정 (`.env`)
프로젝트 루트에 `.env` 파일을 생성하고 계좌 정보를 입력합니다.
```env
KIS_ACC1_KEY=여러분의_API_KEY
KIS_ACC1_SECRET=여러분의_SECRET
KIS_ACC1_NO=계좌번호-01
KIS_ACC1_NAME=계좌별칭

KIS_VIRTUAL=False # True: 모의투자 / False: 실전투자
```

### 3. 프로그램 실행
```bash
streamlit run app.py
```

## 📂 핵심 파일 구조
- `app.py`: 메인 웹 애플리케이션 엔진
- `calculator.py`: 리스크 관리 및 분할 매수 가격 연산 모듈
- `kis_client.py`: 증권사 API 통신 클라이언트
- `kis_websocket.py`: 비동기 시세 데이터 통신망
- `components/`: 레이아웃 전용 UI 파일 모음

## 📚 기술 스택 및 주요 라이브러리 (Tech Stack)
API 소통, 차트 렌더링, 데이터 처리 등 전체 과정에 사용된 핵심 패키지들입니다.

### 🎨 프론트엔드 & UI (웹 대시보드)
- **`streamlit (>=1.30.0)`**: 전체 웹 애플리케이션의 뼈대와 UI를 구성하는 파이썬 전용 풀스택 프레임워크입니다.
- **`streamlit-lightweight-charts`**: 트레이딩뷰(TradingView)의 경량 차트 엔진을 연동하여 빠르고 깔끔한 캔들 차트를 화면에 그립니다.
- **`plotly (>=5.18.0)`**: 보조적인 데이터 시각화 및 인터랙티브 그래프 표출에 사용됩니다.

### 📡 API 통신 & 데이터 수집 (네트워크)
- **`websockets`**: 한국투자증권 실시간 체결가 데이터를 1초 단위로 끊임없이 받아오는 비동기 통신 라이브러리입니다.
- **`requests (>=2.31.0)`**: 잔고 조회, 주문 전송 등 REST API 형태로 한국투자증권 서버와 질의응답을 주고받습니다.
- **`finance-datareader`**: 국내(네이버 금융) 및 해외(야후 파이낸스) 주식의 과거 차트 데이터(OHLCV)를 손쉽게 긁어오는 만능 크롤링 패키지입니다.
- **`pykis`**: 한국투자증권 OpenAPI 명세를 파이썬으로 쉽게 다룰 수 있게 해주는 커뮤니티 라이브러리입니다.

### 💾 데이터 처리 & 백엔드 저장소
- **`pandas (>=2.0.0)`**: 수집된 주가 데이터를 표(데이터프레임) 형태로 변환하고, 분할 매수 타점을 계산하기 위해 사용됩니다.
- **`supabase`**: 앱이 꺼져도 감시 주문(트레일링 스탑 등)이 날아가지 않도록, 클라우드 PostgreSQL 데이터베이스에 데이터를 영구 저장/불러오기 하는 역할을 합니다.
- **`python-dotenv (>=1.0.1)`**: 증권사 API Key나 Supabase 비밀번호를 코드에 직접 노출하지 않고 `.env` 파일로 숨겨서 안전하게 관리합니다.
- **`python-telegram-bot (>=20.7)`**: 주요 타점 도달 및 주문 체결 시 사용자의 스마트폰으로 알림을 보내기 위한 메신저 봇 패키지입니다.
